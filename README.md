# Swyby ML Experiments

Machine learning experiments for activity recommendation algorithms.

Part of [Swyby](https://swyby.io) ecosystem.

## Focus Areas

- Intent classification (social, calm, adventure, romantic)
- Activity ranking and scoring
- Context-aware recommendations (weather, time, location)
- User preference learning

## Tech Stack

- Python 3.12
- scikit-learn
- pandas / numpy
- Jupyter notebooks
